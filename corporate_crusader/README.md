A satirical RPG where you navigate the treacherous world of corporate life, battling office stereotypes and climbing the corporate ladder through wit, caffeine, and questionable ethics.

## 🎯 Game Overview

**Corporate Crusader** is a turn-based RPG that combines classic dungeon-crawler mechanics with the absurd realities of office life. Armed with nothing but a cheap suit and an unhealthy amount of caffeine, you must navigate through a corporate office building, defeating enemies ranging from micromanagers to passive-aggressive coworkers.

### 🏆 Competition-Winning Features

This game was designed to excel in **"Most Fun"** and **"Most Detailed"** categories:

- **Humor**: Clever, layered corporate satire that parodies office culture
- **Detail**: Deep stat systems, unique abilities, and polished UI
- **Replayability**: Random encounters, multiple enemy types, and progression systems
- **Polish**: Professional pygame interface with sound effects

## 🎮 Gameplay Features

### ⚔️ Turn-Based Combat
- Strategic combat with corporate-themed abilities
- **Small Talk**: Confuse enemies with meaningless conversation  
- **Buzzword Bingo**: Deal psychic damage with corporate speak
- **Coffee Break**: Restore caffeine and reduce stress
- **Hostile Takeover**: Ultimate ability to acquire your enemies

### 📊 Character Progression
- **Four Core Stats**: Charisma, Competence, Networking, Cynicism
- **Unique Resources**: Health, Caffeine (mana), Stress (negative status)
- **Equipment System**: Suits, accessories, gadgets, and drinks
- **Level Up**: Gain experience and improve stats

### 🏢 Office Building Exploration
- **20 Floors** of corporate hierarchy to climb
- **Random Encounters**: Combat, events, and loot discovery
- **Progressive Difficulty**: Higher floors have tougher enemies
- **Rest Areas**: Break rooms to recover and strategize

### 👔 Corporate-Themed Everything
- **Enemies**: Micromanagers, Karens, Interns, Executives, IT Guys, HR Reps
- **Equipment**: From "Cheap Polyester Suit" to "Executive Armor"
- **Abilities**: Corporate restructures, networking lunches, passive aggression
- **Currency**: Office Supplies and Influence points

## 🎭 Meet the Corporate Wildlife

### The Micromanager
*"I need to see all your work before you submit it!"*
- **Strategy**: Uses control abilities and blame redirection
- **Weakness**: High stress levels
- **Signature Move**: Questions every decision you've made today

### The Karen
*"I want to speak to your manager!"*
- **Strategy**: Aggressive attacks and complaints
- **Weakness**: Logic and competence
- **Signature Move**: Threatens to leave negative reviews

### The Overeager Intern
*"This internship is my chance to make it big!"*
- **Strategy**: Networking and enthusiasm
- **Immunity**: Cynicism (too optimistic to be affected)
- **Signature Move**: LinkedIn connection requests

### The Ruthless Executive
*"Your position has been deemed... redundant."*
- **Strategy**: Corporate restructures and hostile takeovers
- **Immunity**: Stress and guilt
- **Signature Move**: Acquiring your entire existence

### Navigation
- **Arrow Keys** or **Mouse**: Navigate menus and select options

- **Escape**: Go back or return to main menu

### Combat
- **1 Key**: Basic Attack
- **2 Key**: Use Abilities

- **4 Key**: Attempt to Flee

- **Mouse**: Hover and click for all interactions

## 🚀 Installation & Setup

### Requirements
- **Python 3.9+**
- **Pygame 2.5.0+**
- **Optional**: Pillow for enhanced graphics

### Quick Start
```bash
# Clone or download the game
cd corporate_crusader

# Install dependencies
pip install pygame pillow

# Run the game
python main.py
```

### Alternative Installation
```bash
# Using the requirements file
pip install -r requirements.txt
python main.py
```

## 🐛 Troubleshooting

### Common Issues

**Game Won't Start**
```bash
# Check Python version
python --version

# Reinstall pygame
pip uninstall pygame
pip install pygame
```

**Audio Problems**
- Audio is optional - game works without sound
- Check system audio settings
- Try running with `--no-audio` flag (if implemented)

**Save Game Issues**
- Saves are stored in `data/saves/`
- Manually delete corrupted saves if needed
- Check file permissions

### Performance Optimization
- Lower resolution in UI manager (1024x768)
- Disable audio if experiencing lag
- Close other applications for better performance
